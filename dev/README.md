# dev

The mirror of the dev root (`C:\Dev` by default, the path comes from `personal.yaml`).

`External/` holds the `CLAUDE.md` and `README.md` that `install.ps1` writes into the folder for
other people's repositories. They are a rule template: "read and run this code, do not modify it
unless I ask".

This `README.md` is documentation and is never installed. Nothing else belongs in this folder —
the projects themselves are the owner's and live on his disk, not in this repo.
